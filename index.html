02 / ENCODE

Pixels → parâmetros

A distribuição espacial, a luminosidade e as cores controlam notas, dinâmica e panorâmica, sempre com o mesmo mapeamento para uma fonte.

03 / LISTEN
♫

Instrumentos ao vivo

O Web Audio API sintetiza cada evento diretamente no dispositivo, sem áudio pré-gravado ou conexão com um modelo de música.

04 / UNDERSTAND
⌖

Ciência responsável

Índices derivados das cores renderizadas não são concentrações ou grandezas científicas calibradas. Mostramos sempre origem e limites.
