03 / Explainable science

From pixels to music.

NASA source media → fixed-resolution image analysis → 84-step / 6-band mapping → Web Audio synthesizer.

Visual intensityControls note loudness and activity.
Spatial positionControls pitch band and stereo panorama.
Source identityChooses instrument waveform and visual treatment.
Deterministic, transparent mapping · Image-derived indices ≠ calibrated physical measurements.04 / 07
04 / NASA source data

Real planetary imagery.
Traceable origins.

Our deployment fetches official NASA SVS media and extracts 38 display frames. Missing NASA media never becomes synthetic science.

Source registry: svs.gsfc.nasa.gov · Items 5276, 3912, 5669, 5196, 4950 and 5011.
