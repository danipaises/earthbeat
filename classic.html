02 / METODOLOGIA

Quando os dados ganham voz.

Não são sons gravados no espaço. É ciência transformada em linguagem musical.

01 /
▦

Pixels reais

As imagens de luzes noturnas da NASA são analisadas em uma grade fixa, preservando o mesmo cálculo para todos os anos.

02 /
≋

Dados em notas

Intensidade e distribuição dos pontos iluminados determinam volume e ritmo. A posição vertical define a altura das notas.

03 /
♫

Síntese ao vivo

O navegador gera cada nota em tempo real com Web Audio. Nenhuma trilha pré-gravada é usada para representar os dados.

ⓘ

Nota científica: o áudio interpreta o brilho de imagens processadas, não medições físicas calibradas. A diferença entre anos não prova, isoladamente, mudanças ambientais ou socioeconômicas. As notas são uma representação artística e acessível dos padrões visuais.
